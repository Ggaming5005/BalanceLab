# Changelog

## 0.1.0

- Pure Luau event-based progression model for one currency and a currency or loot goal.
- Exponential, linear and power upgrade curves; efficient and eager player strategies.
- First-success loot probabilities, hard pity, median and upper-percentile play times.
- Native Studio editor with three presets, pinned comparisons, charts, milestones and longest waits.
- Validated JSON editing, explicit selected-module import and undoable configuration export.
- Finite numeric bounds, generated-curve validation, cancellation and computation limits.
